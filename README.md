# Tokyo Mate 東京通

給東京自由行旅客的實用 Web App —— 把常用的旅遊翻譯、問答、地圖與日文表達工具，集中在一個手機瀏覽器就能開啟的小幫手。

不需要懂日文，也不需要熟悉東京，就能即時翻譯、詢問旅遊問題、拍照翻譯看不懂的文字、探索附近的景點與美食，並在需要開口說日文時，快速找到合適的一句話。Tokyo Mate 重視手機操作體驗，目前已有 6 項可以實際使用的功能。

## ✨ 目前功能

首頁提供以下 6 個功能入口：

### 💬 即時翻譯
語音或文字輸入，中日文雙向即時翻譯，並可播放語音，適合旅途中臨時需要溝通的場合。

### 🗣️ 問東京
針對東京旅遊情境的智能問答，包含營業時間、票價、交通方式，以及遇到緊急狀況時的協助建議。

### 🗺️ 探索附近
使用目前位置或手動輸入地區（例如淺草、上野、新宿），搜尋附近的景點、美食、購物與車站，並可一鍵在 Google Maps 開啟導航前往。

### 📖 東京百科
離線可瀏覽的東京旅遊知識內容，依類別與距離篩選景點、餐廳、車站與緊急設施資訊。

### 📷 拍照翻譯
拍攝或選擇既有照片，框選想辨識的文字範圍，即可將菜單、招牌、車站資訊等翻譯成繁體中文或日文，並可播放語音。

### 🈂️ 旅遊日文
依照機場、飯店、點餐等旅行情境，快速找到自然、簡單、合適的日文說法，看得懂繁中、也能直接把日文展示或播放給對方看／聽。

## 🎌 Feature 004：旅遊日文｜Travel Japanese

**「旅行時知道自己想說什麼，卻不知道怎麼用日文表達」** —— 這是旅遊日文想解決的問題。

核心體驗很單純：

> 選擇旅行情境 → 找到一句話 → 看繁體中文確認意思 → 看日文文字 → 需要時播放語音給對方聽

### 目前涵蓋 7 個旅行情境

- ✈️ 機場
- 🏨 飯店
- 🍜 餐廳點餐
- 🛍️ 購物
- 🚇 交通
- 🆘 求助／緊急狀況
- 💬 日常溝通

### 主要能力

- **依情境瀏覽常用句**：每個情境都收錄了大量高實用性的句子
- **日文＋繁體中文 Phrase Card**：一張卡片同時看到日文與自然的繁中翻譯
- **快速搜尋**：輸入部分繁中或日文關鍵字，直接找到對應句子
- **收藏「我的常用句」**：把常用的句子收藏起來，重複行程不必重新尋找
- **日文語音播放**：支援瀏覽器日文語音播放；實際可用語音依裝置與瀏覽器而異
- **求助／緊急狀況安全提醒**：緊急與求助用語附有安全提醒，內容作為溝通輔助，不取代警察、醫療或其他正式協助

內建超過 100 句實用旅遊日文（108 個 unique phrases），依 7 大旅行情境整理，共 148 個情境分類收錄。

> 旅遊日文目前不是即時 AI 造句、不是 Chatbot、也不提供發音評分；它是一份精選、可信賴、可直接使用的常用句工具。

## 🚀 如何使用

1. 打開 Tokyo Mate，在首頁輸入想說的話，或點選「麥克風」以語音輸入
2. 點選「即時翻譯」或「問東京」，取得翻譯或旅遊建議
3. 點選「探索附近」，尋找附近的景點、美食或車站，並可前往目的地
4. 點選「拍照翻譯」，翻譯看不懂的菜單、招牌或標示
5. 點選「東京百科」，離線瀏覽旅遊知識內容
6. 點選「旅遊日文」，依情境找到、查看並播放合適的日文句子

## 🗺️ Nearby Map 使用方式

1. 進入「探索附近」，選擇「使用我的位置」或手動輸入地區並選擇類別搜尋
2. 在下方 result cards 或上方地圖查看搜尋結果
3. 點選任一張 card 或地圖上的地點，選定同一個地方
4. 對已選定且具備可靠位置資訊的地點，點選「前往此地」
5. 系統會開啟 Google Maps 繼續導航

若目前位置無法取得或地圖暫時無法載入，仍可直接使用 result cards 完成選取與前往此地。

## 📷 Photo Translate 使用方式

1. 進入「拍照翻譯」，選擇「拍攝照片」或「選擇既有照片」
2. 在照片上框選要辨識的文字範圍並確認
3. 系統辨識選取範圍內的文字，顯示 OCR 原文
4. 選擇翻譯目標語言（繁體中文或日本語），查看翻譯結果
5. 點選播放，聽取與翻譯結果相同語言的語音
6. 若辨識或翻譯結果不理想，可重新框選範圍再次辨識，不必重新拍照

## 🈂️ 旅遊日文使用方式

1. 進入「旅遊日文」，從 7 個旅行情境中選擇一個（或直接使用搜尋）
2. 瀏覽該情境下的句子卡，先看繁體中文確認意思，再查看日文
3. 點選播放，讓手機直接播放日文語音給對方聽
4. 點選收藏，把常用的句子加入「我的常用句」，下次不必重新尋找
5. 進入「求助／緊急狀況」情境時，安全提醒會直接顯示在畫面上

## 🛡️ Privacy & Safety

- 麥克風只在使用者主動點選「語音輸入」時才請求權限
- 定位只在使用者選擇「使用我的位置」時才請求權限，也可以改用手動輸入地區
- 相機只在使用者主動選擇「拍攝照片」時才請求權限
- 不建立長期聊天記錄、照片歷史或位置歷史，也不做背景定位追蹤
- 拍照翻譯的照片、原文與翻譯結果只存在於當次任務，離開或更換照片即清除
- 旅遊日文的收藏清單僅儲存在裝置本機（`localStorage`），不需要帳號，也不會同步到雲端或其他裝置
- 求助／緊急狀況情境的用語附有安全提醒：內容作為溝通輔助，不取代警察、醫療或其他正式協助，也不保證翻譯完全準確或對方必定理解
- 所有 API 金鑰與服務憑證僅存放於 server-side environment variables，不會出現在前端程式碼中

## 💻 Local Development

### Prerequisites

- Node.js >= 18
- npm >= 9

### Install dependencies

```bash
npm install
cp .env.example .env.local
```

### Environment variables

依 `.env.example` 在 `.env.local` 設定以下變數名稱（僅本機使用，不會被提交）：

```env
OPENAI_API_KEY=
OPENAI_MODEL=gpt-4o-mini
GOOGLE_PLACES_API_KEY=
VITE_GEOAPIFY_API_KEY=
```

- `OPENAI_API_KEY`、`OPENAI_MODEL`、`GOOGLE_PLACES_API_KEY`：server-side secrets，僅供 `api/` 目錄下的 serverless functions 使用，不會暴露給瀏覽器
- `VITE_GEOAPIFY_API_KEY`：browser-visible 設定，用於前端載入地圖圖磚
- 請勿在任何地方填入真實金鑰後提交至版本控制

## 📁 Project Structure

```
api/            Vercel serverless functions（翻譯、OCR、語音、地點查詢等後端 API）
src/screens/    App 的主要畫面（首頁、助手、探索附近、拍照翻譯、旅遊日文、知識庫）
src/features/   各功能的元件與邏輯（emergency、nearby、photo-translate、speech、translation、travel、travel-japanese、knowledge）
src/services/   前端與 API 溝通、定位、旅遊日文 dataset 查詢等共用服務
src/data/tokyo/ 東京旅遊知識庫內容
specs/          各功能的規格、計畫與驗收文件
docs/verification/ 驗證報告
```

旅遊日文延續 Tokyo Mate 既有架構風格：frontend-first、內建本地 dataset、本地搜尋，語音播放使用瀏覽器原生 `SpeechSynthesis`，收藏使用 `localStorage`，未新增後端服務或資料庫。
